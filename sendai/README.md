# 仙台市 3Dトピックマップ

宮城県仙台市（全5区）を **3Dマップ** で表示し、名所・歴史・文化・イベント・グルメ・自然・スポーツにゆかりのある場所に、**漫画の吹き出し** でトピックを表示するWebアプリです。[さいたま市版](../README.md) と同じ仕組みで、仙台市の **最新ニュース・オタク関連の情報・事件/防犯情報・ジャンル別のグルメ情報・スーパーの特売情報・地域の口コミ** も自動で取得し、記事に出てくる地名の場所に吹き出しで表示します。

- 公開URL：`https://<ユーザー名>.github.io/saitama-3d-map/sendai/`
- **APIキー不要・無料サービスのみ** で動作します
- 画面と機能（3Dマップ・吹き出し・一覧と検索・ライブカメラ・ハザードマップ・天気・デザインの切り替えなど）は、さいたま市版と共通です。使い方はリポジトリ直下の [README](../README.md) を見てください

## さいたま市版との違い

プログラム（`../app.js`・`../style.css`）は共通で、市ごとに違うところは `city.js` と `data/`・`scripts/` の設定に書いています。

| | 仙台市版 |
|---|---|
| 初期視点 | 都心部を中心に、泉区から太白区・若林区の沿岸部まで（西部の秋保・作並・泉ヶ岳・定義は地図を動かして見る） |
| 地形の強調 | 1.3倍（西部は山地なので、平坦なさいたま市の1.8倍より弱め） |
| 天気予報 | 気象庁「宮城県東部」の予報と、気温の地点「仙台」 |
| 警報・注意報 | 気象庁は仙台市を「仙台市東部」「仙台市西部」に分けて発表するので、区域ごとに表示します |
| 地震 | 「仙台市の震度」は市内5区（青葉区・宮城野区・若林区・太白区・泉区）で最も大きいもの |
| 事件・防犯 | 宮城県警察のサイト（みやぎSecurityメール・子供と女性のための安全情報 など）を案内します |

- **配信元のページで見るもの**：せんだいメディアテーク（定禅寺通）、愛宕神社から望む仙台市街、仙台市天文台から見た空、ウェザーニュースのライブカメラ（区ごと・20か所）

同じチャンネルが複数の場所を配信しているカメラは、`titleKeywords` でタイトルに含まれる語（「仙台城跡 Live」「大橋」「マークワン」「泉中央」「五橋」など）を指定し、正しい配信を選んでいます。配信中の動画は GitHub Actions が3時間ごとに調べ直します（`python3 scripts/fetch_livecams.py --city sendai`）。地図上のカメラの位置はおおよそです（ウェザーニュースは区役所の位置）。

## ニュースの取得

`python3 scripts/fetch_news.py --city sendai` で、`sendai/scripts/news_sources.json` の取得元から集め、`sendai/scripts/places.json` の地名辞書で位置を推定して `sendai/data/news.json` に書き出します（GitHub Actions が3時間ごとに実行）。

位置の推定では、仙台市の地名と同じ文字を含む別の場所や語を除いています。

- 横浜市の **青葉区**・**泉区**（「横浜市青葉区」「横浜市泉区」など）
- 相撲の **宮城野部屋**・宮城野親方
- 金沢市の **長町**（長町武家屋敷）、東京都千代田区の **一番町**
- 人名と紛らわしい語（「愛子」「大橋」「荒井」「上杉」など）や、ほかの県にもある地名（「荒浜」など）は、地名辞書に入れないか、「愛子駅」「荒井駅」「仙台市荒浜」のような形でだけ入れています

## ファイル構成

```
sendai/index.html                画面の骨組み（../app.js・../style.css を読み込む）
sendai/city.js                   仙台市の設定（初期視点・地図の範囲・気象庁のコード・警察のサイトなど）
sendai/data/topics.json          カテゴリ・区・トピックのデータ
sendai/data/news.json            最新ニュース（GitHub Actions が自動更新）
sendai/data/livecams.json        ライブカメラの一覧と配信状況（GitHub Actions が自動更新）
sendai/scripts/news_sources.json ニュースの取得元とカテゴリ分けの設定
sendai/scripts/places.json       位置推定に使う地名辞書
```
