# 東京23区 3Dトピックマップ

東京23区を **3Dマップ** で表示し、名所・歴史・文化・イベント・グルメ・自然・スポーツにゆかりのある場所に、**漫画の吹き出し** でトピックを表示するWebアプリです。[仙台市版](../sendai/README.md)・[さいたま市版](../README.md) と同じ仕組みで、23区の **最新ニュース・オタク関連の情報・事件/防犯情報・害獣出没・ジャンル別のグルメ情報・スーパーの特売情報・地域の口コミ** も自動で取得し、記事に出てくる地名の場所に吹き出しで表示します。

- 公開URL：`https://<ユーザー名>.github.io/saitama-3d-map/tokyo/`
- **APIキー不要・無料サービスのみ** で動作します
- 画面と機能（3Dマップ・吹き出し・一覧と検索・ライブカメラ・ハザードマップ・天気・デザインの切り替えなど）は、ほかの版と共通です。使い方はリポジトリ直下の [README](../README.md) を見てください。ヘッダーの「🗺 ほかの地域」で、さいたま市版・仙台市版に移れます

## ほかの版との違い

| | 東京23区版 |
|---|---|
| 初期視点 | 23区全体（東西約30km）が見えるように斜め上から |
| 天気予報 | 気象庁「東京地方」の予報と、気温の地点「東京」 |
| 警報・注意報 | 気象庁は区ごとに発表するので、同じ警報・注意報が出ている区をまとめて表示します（全部の区なら「23区すべて」） |
| 地震 | 「東京23区の震度」は23区で最も大きいもの |
| 事件・防犯 | 警視庁のサイト（メールけいしちょう など）を案内します |
| 害獣出没（🦝） | ハクビシン・アライグマ・タヌキ・イノシシ・サル・クマ・カラスの出没などを伝える報道です（公式の出没データは使っていません） |
| ライブカメラ | カメラが多いので、近いカメラをまとめる範囲をほかの版より広くしています |

## ニュースの取得

`python3 scripts/fetch_news.py --city tokyo` で、`tokyo/scripts/news_sources.json` の取得元から集め、`tokyo/scripts/places.json` の地名辞書で位置を推定して `tokyo/data/news.json` に書き出します（GitHub Actions が3時間ごとに実行）。

23区は全国のニュースに出てくる地名が多いので、次のようにしています。

- **中央区・港区・北区** はほかの政令市（大阪市・札幌市・名古屋市など）にもあるので、「東京都中央区」「東京・港区」のような形のときだけ東京の区とみなします
- 「東京」「都内」だけでは23区の記事とみなしません（全国の記事が「都内で会見」などと書くため）。区名か、地名辞書の地名を含む記事だけを入れます
- 大阪の日本橋（にっぽんばし）、名古屋の丸の内、岡山の後楽園、川崎の等々力、地下鉄の「銀座線」「浅草線」などは、23区の地名として扱いません
- 人名と紛らわしい地名（上野・大塚・青山・大泉など）は、「上野駅」「上野公園」「大泉学園」のような形でだけ地名辞書に入れています

## ファイル構成

```
tokyo/index.html                画面の骨組み（../app.js・../style.css を読み込む）
tokyo/city.js                   東京23区の設定（初期視点・地図の範囲・気象庁のコード・警視庁のサイトなど）
tokyo/data/topics.json          カテゴリ・区・トピックのデータ
tokyo/data/news.json            最新ニュース（GitHub Actions が自動更新）
tokyo/data/livecams.json        ライブカメラの一覧と配信状況（GitHub Actions が自動更新）
tokyo/scripts/news_sources.json ニュースの取得元とカテゴリ分けの設定
tokyo/scripts/places.json       位置推定に使う地名辞書
```
