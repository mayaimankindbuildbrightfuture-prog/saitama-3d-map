# saitama-3d-map

埼玉県さいたま市（全10区）を **3Dマップ** で表示し、名所・歴史・文化・イベント・グルメ・自然・スポーツにゆかりのある場所に、**漫画の吹き出し** でトピックを表示するWebアプリです。さいたま市の **最新ニュース・オタク関連の情報・事件/防犯情報・ジャンル別のグルメ情報・スーパーの特売情報・地域の口コミ** も自動で取得し、記事に出てくる地名の場所に吹き出しで表示します。

- ビルド不要の静的サイト（`index.html` + `app.js` + `style.css` + `data/topics.json`）
- **APIキー不要・無料サービスのみ** で動作します

## 主な機能

- **3Dマップ**：MapLibre GL JS 4.7.1 で、OpenFreeMap のベクタータイル（OpenStreetMap データ）と3D建物（fill-extrusion）を表示します。AWS Terrain Tiles の標高データで地形と陰影も付けています。斜め上からの立体表示で始まります。
- **操作**
  - パン：左ドラッグ
  - 回転・傾き：右ドラッグ、または Ctrl＋ドラッグ（スマホは2本指）
  - 拡大・縮小：マウスホイール、ピンチ、ズームボタン
  - 右上にコンパスとズームボタン（NavigationControl）、その下に **初期視点へ戻るボタン（⟲）**
- **漫画の吹き出し**：白地に太い黒枠で、しっぽが地点を指します。フォントは Google Fonts の「Yusei Magic」です。地図の回転・ズームに追従し、カテゴリごとに色分けしています。ズームアウト時は小さく表示され、重なる吹き出しは丸いアイコンにまとまります。
- **詳細パネル**：吹き出しをクリックすると、その地点へ飛び（flyTo）、詳細・年代・アクセス・公式サイト・関連トピック・近くのトピックを表示します。PCでは右側のパネル、スマホでは下部シートです。関連トピックをクリックすると、そのトピックへ移動します。
- **カテゴリフィルタ**：ヘッダーのボタンで表示を切り替えます。ダブルクリックするとそのカテゴリだけを表示します。
- **一覧・検索**：キーワードでトピックを絞り込めます。Enterで先頭の結果へ移動します。
- **区へ移動**：10区それぞれの付近へ視点を移動します。
- **最新ニュース**：GitHub Actions が3時間ごとにニュースを取得し、`data/news.json` を更新します。新聞風の吹き出し（NEWSタグ付き）で地図に表示し、クリックすると見出し・配信元・日時・記事へのリンクを表示します。トピックの詳細には「この付近のニュース」も出ます。ヘッダーの「📰 ニュース」をダブルクリックすると、ニュースだけを表示できます。
- **オタク情報（🎮）**：アニメ・漫画、コラボカフェ・グッズ、コスプレ・同人、VTuber・声優・アイドル、ゲーム・eスポーツなどのイベントや話題です。
- **事件・防犯（🚨）**：警察発表などをもとにした事件の報道で、詐欺、性犯罪・盗撮、不審者・声かけ、暴力・凶悪事件、窃盗・盗難、交通犯罪に分類します。詳しくは下の「事件・防犯情報について」を見てください。
- **グルメ情報（🍜）**：新店・フェアなどの記事を、立ち飲み屋・食べ放題・居酒屋・カレー・ラーメン・中華・和食・焼肉・洋食・カフェ/スイーツ・その他のジャンルに分け、ジャンルの絵文字付きの吹き出しで表示します。
- **スーパー特売（🛒）**：スーパー各社のセール・特売・新店/リニューアル・閉店などを伝える記事です。毎週のチラシそのものは取得できないため、詳細パネルからチラシサイト（Shufoo!・トクバイ）へ案内します。
- **口コミ（💬）**：SNS（Bluesky・Misskey・Mastodon）に公開されている、さいたま市内の地名を含む投稿です。グルメ・お店、買い物、交通・道路、子育て・学校、公園・自然・季節、イベント・お出かけ、住みやすさ・暮らし、つぶやきに分類します。詳しくは下の「口コミについて」を見てください。
- **起動時の表示**：見やすさのため、起動時は「📰 ニュース」だけがオンです。ほかのカテゴリはボタンでオンにしてください。「✅ すべて表示」で全部オンにでき、もう一度押すとニュースだけに戻ります。
- **ライブカメラ（📹）**：さいたま市内のライブカメラの場所が、最初から地図にボタンで出ています。市全体を見ているときはカメラ同士が重なるので「📹 ライブカメラ 3」の1つのボタンにまとまり、押すと近づいてカメラごとのボタンに分かれます。地図右上の「📹 カメラ」で、カメラのボタンを隠したり出したりできます。カメラを押すと、画面の左下4分の1に映像が出ます（スマホでは画面の下部）。映像の上の「↗ 配信サイトへ」で配信元のページを開き、「✕ 閉じる」で映像を閉じます。詳しくは下の「ライブカメラについて」を見てください。
- **トピックを閉じると元の視点に戻る**：吹き出しをクリックするとその場所へズームし、詳細を閉じる（✕ または Esc キー）と、開く前のズーム・傾き・向きに戻ります。関連トピックを次々に開いた場合も、最初に開く前の視点に戻ります。
- **デザインの切り替え**：ヘッダーの「🎈 ポップ」のメニューで、画面のデザインを5種類から選べます。選んだデザインはブラウザに保存され、次に開いたときもそのデザインになります。
  - 🎈 ポップ：太い黒枠と漫画風の文字（最初のデザイン）
  - 🧊 クール：暗い背景にネオンの水色。地図も夜のような暗い色になります
  - ◻️ シンプル：白と細い線。飾りを減らした落ち着いたデザイン
  - 📻 ノスタルジック：セピア色の紙と手書き風の文字
  - 👑 豪華：黒と金、二重の金の枠と明朝体
- **ジャンルで絞り込み**：ヘッダーの「🍴 ジャンルで絞り込み」で、「カレー」「詐欺」「コスプレ・同人」などの分類だけを地図と一覧に表示できます。
- **URL共有**：`#topic=railway-museum` のようなURLで、特定のトピックを開いた状態で表示できます。

## 起動方法（ローカル）

`fetch` で `data/topics.json` を読み込むため、`index.html` をダブルクリックで直接開くのではなく、ローカルサーバー経由で開いてください。

```bash
# Node.js がある場合
npx serve .

# Python がある場合
python -m http.server 8000
# → ブラウザで http://localhost:8000/ を開く
```

インターネット接続が必要です（地図タイル・ライブラリ・フォントをCDNから読み込みます）。ベースマップを取得できない場合は簡易表示に切り替わり、吹き出しと詳細表示はそのまま使えます。

## GitHub Pages での公開方法

1. このリポジトリを GitHub にプッシュします（`main` ブランチ）。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** を「**GitHub Actions**」にします。
4. **Actions** タブで「ニュース更新と公開」を **Run workflow** で実行します（以後は `main` へのプッシュ時と3時間ごとに自動で実行されます）。
5. 数分後に `https://<ユーザー名>.github.io/saitama-3d-map/` で公開されます。

ビルド工程は無いので、ファイルをプッシュするだけで更新されます。Pages を使わない場合も、ワークフローは `data/news.json` の更新だけを行います。定期実行（schedule）はデフォルトブランチ（`main`）にワークフローがあるときだけ動きます。非公開リポジトリで GitHub Pages を使うには、有料プラン（GitHub Pro など）が必要な場合があります。

## 最新ニュースの仕組み

ブラウザから直接ニュースサイトを読み込むことはできない（CORSの制限）ため、次のように取得しています。APIキーは使いません。

1. `.github/workflows/update-news.yml` が **3時間ごと**（と手動実行・`main` へのプッシュ時）に動きます。
2. `scripts/fetch_news.py` が `scripts/news_sources.json` に書かれたRSSを取得します。初期設定では、Googleニュース検索を目的別に19種類、SNS（Bluesky 12・Misskey 8・Mastodon 48）を68種類、合わせて87種類の取得元を使います。
   - 一般ニュース（「さいたま市」など、直近7日）
   - オタク関連（「さいたま アニメ・声優・コスプレ」など、直近30日）
   - 事件（「さいたま市 逮捕・詐欺・不審者」「さいたま市内の警察署」など、直近7〜14日）
   - グルメ（「さいたま市 ラーメン」「さいたま市 カレー」「さいたま市 食べ放題」など、直近30日）
   - スーパーの特売（「さいたま市 スーパー 特売」、スーパー各社名など、直近14日）
   - 口コミ（直近30日）
     - Bluesky の公開検索（「さいたま市」「大宮駅」「浦和駅」「岩槻」「与野」「さいたま新都心」など12の検索語）
     - Misskey（misskey.io）のハッシュタグ検索（#さいたま・#大宮・#浦和 など8種類）
     - Mastodon（mstdn.jp・fedibird.com・mastodon.social・pawoo.net）のハッシュタグRSS（#さいたま・#浦和・#大宮・#与野・#岩槻・#北浦和 など12種類）
3. 見出し・概要に含まれるキーワードで、記事を **事件・防犯 → オタク → スーパー特売 → グルメ情報 → ニュース** の順に振り分けます。SNSの投稿は、内容にかかわらず「口コミ」にします。さらにジャンル（グルメ）・種類（事件）などの細かい分類も付けます。キーワードは `news_sources.json` の `categories` で変えられます。一般ニュースの検索で見つかった記事でも、たとえば「食べ放題」を含めばグルメ情報になります。
4. 見出し・概要に出てくる地名を `scripts/places.json` の地名辞書と照合して、位置を推定します。優先順位は「施設」＞「駅」＞「地域名・区名」です。どれにも当てはまらない記事は「市全体のニュース」として市役所付近に表示します。
5. 次の記事を除き、カテゴリごとの上限（ニュース40件・オタク30件・事件30件・グルメ40件・スーパー30件・口コミ150件。口コミは1つのSNSから最大60件）まで `data/news.json` に保存してコミットします。
   - 重複している記事。見出し末尾の「（媒体名）」「｜サイト名」は取り除いてから比べ、言い回しがほとんど同じ見出しも重複とみなします。
   - 映画の上映時間・天気予報・不動産の物件情報など、除外対象の配信元や語句に当てはまる記事（`scripts/news_sources.json` の `excludeSources`・`excludeWords`）。
   - 古い記事（ニュース・事件は14日、オタク・グルメは30日より前）と、さいたま市と無関係な記事。
6. 同じワークフローで GitHub Pages に公開するので、サイトにも自動で反映されます。開いたままの画面も15分ごとに読み直します（一覧の🔄ボタンでも読み直せます）。

位置は地名から機械的に推定しているので、実際の場所と異なることがあります（詳細パネルに「記事中の『○○』から推定」と表示されます）。キーワードによる分類も機械的なので、記事の内容と分類が合わないことがあります。

### ライブカメラについて

`data/livecams.json` に、さいたま市内で YouTube のライブ配信をしているカメラを登録しています（場所は映っている範囲のおおよその位置です）。

| カメラ | 場所 | 配信 |
|---|---|---|
| 北浦和〜与野 鉄道ライブカメラ | 浦和区（JR北浦和駅〜与野駅の間） | かどりつ（YouTube） |
| 大宮操車場・さいたま新都心 鉄道ライブカメラ | 大宮区・中央区 | くまくまくまチャンネル（YouTube。1日2回の配信に分かれる） |
| 大宮駅東口・大門町中央通り お天気カメラ | 大宮区 | FLAT（YouTube） |

- YouTube のライブ配信は、配信ごとに動画のURLが変わります。そのため `scripts/fetch_livecams.py` がチャンネルの公開ページから **チャンネルID** を調べ、画面では「そのチャンネルで今配信中のライブ」を埋め込みます。GitHub Actions がニュースと一緒に3時間ごとに実行し、そのとき配信中だったかも記録します（配信中なら地図のカメラに「LIVE」と出ます）。
- 配信時間外や配信が終わったカメラは、映像の代わりに YouTube の「配信していません」などの表示になります。その場合は「↗ 配信サイトへ」から確認してください。
- 河川の監視カメラ（さいたま市水位情報システム・埼玉県 川の防災情報・国土交通省 川の防災情報）は静止画で、各サイト上でしか見られないため、映像パネルの下に公式サイトへのリンクを出しています。
- カメラを追加するときは、`cameras` に `{"id", "title", "description", "ward", "lat", "lng", "provider", "siteUrl", "youtube": {"handle": "@チャンネル名"}}` を足してください（チャンネル名が分からないときは `"seedVideos": ["過去の配信の動画ID"]`）。

### 口コミについて

さいたま市に住む人の声を、APIキーなしで集めるため、次の3つのSNSの公開投稿を使っています。X（旧Twitter）はAPIキーが必要なため使っていません。

- **Bluesky**：公開の検索API（`api.bsky.app` の `searchPosts`）で、さいたま市内の地名を含む日本語の投稿を検索します。この検索は認証なしでは使えなくなる場合があると報告されています。その場合は Bluesky だけが取得できず、ほかの取得元はそのまま動きます（GitHub Actions のログに `[warn]` が出ます）。
- **Misskey**：misskey.io のハッシュタグ検索（`notes/search-by-tag`）を使います。ボットとして登録されたアカウント、注意書き（CW）付きの投稿、公開範囲が限定された投稿は使いません。
- **Mastodon**：各サーバーのハッシュタグRSS（`/tags/タグ.rss`）を使います。

- 投稿者がさいたま市に住んでいるかどうかは確認できません。内容は投稿者個人の感想です。
- 画面には本文と投稿へのリンクだけを出し、投稿者の名前は表示しません。
- ニュースやブログを自動で転載するアカウント（アカウント名・サーバー名に rss・bot・news・blog などを含むもの）の投稿と、リンクの紹介だけの投稿は除きます。
- 不適切な言葉を含む投稿は除きます（`news_sources.json` の `reviews.excludeWords`）。
- 宣伝・懸賞・相互フォロー募集、性的なサービスの広告、天気・運行情報・チェックインなどの自動投稿は除きます（`reviews.excludeWords`）。
- 新しい投稿の多い Bluesky だけで埋まらないよう、1つのSNSから入れるのは最大60件です（`reviews.maxPerService`）。
- 検索語・ハッシュタグ・サーバーは `news_sources.json` の `sources` で増やせます。例:
  - Bluesky: `{"type": "bluesky", "queries": ["大宮公園", "浦和美園"], "category": "reviews"}`
  - Misskey / Mastodon: `{"type": "mastodon", "instances": ["mstdn.jp"], "tags": ["与野本町"], "category": "reviews"}`

### スーパーの特売情報について

Shufoo! やトクバイなどのチラシサイトには、プログラムから読み取れる公開の配信（APIキー不要のもの）がありません。そのため、スーパーのセールや新店を伝えるニュース・プレスリリース（Googleニュース経由）を表示しています。毎週のチラシの中身は、詳細パネルのリンクから各サイトで確認してください。

### 事件・防犯情報について

埼玉県警察は、犯罪や不審者の情報をメールマガジン「犯罪情報官NEWS」、X（旧Twitter）、LINE、Yahoo!防災速報などで発信しています。ただし、APIキーなしでプログラムから読み取れる公式のRSSなどは見つかりませんでした。そのため、このアプリでは **報道機関が伝えた警察発表などのニュース（Googleニュース経由）** を表示しています。

- 地図の位置は記事中の地名（区・駅など）からの推定で、事件の正確な発生場所ではありません。
- 詳細パネルには、[埼玉県警察の公式サイト](https://www.police.pref.saitama.lg.jp/)で最新の正確な情報を確認するよう案内を表示します。
- 公式のRSS/Atomフィードが見つかった場合は、`news_sources.json` の `sources` に `"category": "crime"` を付けて追加できます。

### 手動でニュースを更新する

- GitHub の **Actions** タブ →「ニュース更新と公開」→ **Run workflow**
- 手元で実行する場合（Python 3.9以上、追加ライブラリ不要）:

```bash
python3 scripts/fetch_news.py            # data/news.json を更新
python3 scripts/fetch_news.py --dry-run  # 書き込まずに結果だけ表示
python3 -m unittest discover -s tests    # テスト（ネットワーク不要）
```

### 取得元・地名を追加する

- `scripts/news_sources.json` の `sources` に、RSS 2.0 または Atom のURLを追加できます（例：さいたま市や区の公式サイトの新着情報フィード）。
- 不要な記事が多い場合は、同じファイルの `excludeSources`（配信元名の一部）や `excludeWords`（見出し・概要に含まれる語）に追加してください。重複の判定が厳しすぎる・緩すぎる場合は `duplicateSimilarity`・`duplicateOverlap`（0〜1、大きいほど判定が厳しくなり、残る記事が増える）で調整できます。
- `scripts/places.json` に `{"name": "...", "kind": "facility", "lat": ..., "lng": ..., "aliases": ["..."]}` を追加すると、その地名を含む記事がその場所に表示されます。

## ファイル構成

```
index.html        画面の骨組み（MapLibre・Google Fonts を固定バージョン／URLで読み込み）
style.css         吹き出し・パネル・スマホ用下部シートなどのスタイル
app.js            地図の初期化、3D建物・地形、吹き出しマーカー、重なり回避、詳細表示、検索・フィルタ、ニュース表示
data/topics.json  カテゴリ・区・トピックのデータ
data/news.json    最新ニュース（GitHub Actions が自動更新）
data/livecams.json        ライブカメラの一覧と配信状況（GitHub Actions が自動更新）
scripts/fetch_news.py     ニュースの取得と位置推定（Python 標準ライブラリのみ）
scripts/fetch_livecams.py ライブカメラの YouTube チャンネルIDと今の配信を調べる
scripts/news_sources.json ニュースの取得元（RSS/Atom）
scripts/places.json       位置推定に使う地名辞書
tests/                    fetch_news.py・fetch_livecams.py のテスト
.github/workflows/update-news.yml  定期取得と GitHub Pages への公開
```

## トピックデータの形式（`data/topics.json`）

```jsonc
{
  "id": "railway-museum",          // 一意なID（URLの #topic= にも使用）
  "category": "landmark",          // categories のキー
  "title": "鉄道博物館",
  "bubble": "本物の車両がずらり！",   // 吹き出しに出す短い一言
  "ward": "大宮区",
  "lat": 35.9214, "lng": 139.6177,
  "priority": 1,                   // 1が最優先。重なったとき優先して吹き出しを表示
  "era": "2007年開館",
  "description": "詳細説明",
  "access": "アクセス",
  "url": "https://...",            // 公式・参考サイト（無ければ空文字）
  "related": ["omiya-station"]     // 関連トピックのid
}
```

カテゴリ（`categories`）の色・アイコン・表示名もこのファイルで変更できます。
